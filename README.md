# Aldis Valdehueza — Personal Profile

A two-page personal profile website built with Nuxt 4, Vue, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Nuxt (usually `http://localhost:3000`).

## Pages

- `/` — Welcome page and introduction
- `/profile` — Personal information, education, projects, skills, interests, and hobbies
